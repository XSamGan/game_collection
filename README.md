- **Тема:** Коллекция игр

- **Группа:** ИСиП1-9-24

## 2. Описание проекта

Game Collection — веб-приложение для ведения личной коллекции видеоигр. Пользователь может добавлять игры, редактировать информацию о них, отслеживать игровой прогресс, выставлять оценки и просматривать статистику.

Приложение предназначено для учёта игр, приобретённых или запущенных на сторонних платформах. Оно не является игровым магазином или лаунчером.

## 3. Используемые технологии

- **Backend:** Python, FastAPI.
- **База данных:** SQLite.
- **ORM:** SQLAlchemy 2.0.
- **Миграции:** Alembic.
- **Валидация данных:** Pydantic.
- **Авторизация:** SessionMiddleware, cookie-сессии.
- **Frontend:** HTML, CSS, JavaScript.
- **Внешний API:** RAWG Video Games Database API.

## 4. Установка и запуск

Клонирование репозитория:

```bash
git clone https://github.com/XSamGan/game_collection.git
cd game_collection
```

Создание виртуального окружения:

```bash
python -m venv venv
```

Активация окружения (Windows):

```bash
venv\Scripts\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

### Настройка переменных окружения

В папке `app` необходимо создать файл `.env` на основе `.env.example`.

Указать собственные значения:

```env
SECRET_KEY=your-secret-key
RAWG_API_KEY=your-rawg-api-key
```

Для генерации секретного ключа:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

API-ключ RAWG можно получить после регистрации на сайте [RAWG](https://rawg.io/apidocs).

### Подготовка базы данных

```bash
alembic upgrade head
```

### Запуск приложения

```bash
uvicorn app.main:app --reload
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000

Документация API Swagger:

http://127.0.0.1:8000/docs

## 5. Структура базы данных

В проекте используются четыре таблицы:

- **User** — пользователи приложения.
- **Game** — игры в личных коллекциях пользователей.
- **Platform** — игровые платформы.
- **Status** — статусы прохождения игр.

## 6. API Endpoints

### Авторизация

- **POST `/api/auth/register`** — регистрирует нового пользователя.
- **POST `/api/auth/login`** — выполняет вход пользователя.
- **POST `/api/auth/logout`** — выполняет выход пользователя.
- **GET `/api/auth/me`** — проверяет сессию и возвращает данные текущего пользователя.

### Игры

- **GET `/api/games`** — получает список игр текущего пользователя.
- **GET `/api/games/{id}`** — получает одну игру по ID.
- **POST `/api/games`** — добавляет новую игру.
- **PATCH `/api/games/{id}`** — изменяет данные игры по ID.
- **DELETE `/api/games/{id}`** — удаляет игру по ID.
- **GET `/api/games/top`** — показывает лучшие игры по оценке.
- **GET `/api/games/stats`** — возвращает статистику по играм.

### Платформы

- **GET `/api/platforms`** — получает список платформ.
- **GET `/api/platforms/{id}`** — получает платформу по ID.
- **POST `/api/platforms`** — добавляет новую платформу.
- **DELETE `/api/platforms/{id}`** — удаляет платформу.

### Статусы

- **GET `/api/statuses`** — получает список всех статусов.

## 7. Основные возможности

- Регистрация, авторизация и выход из аккаунта.
- Добавление, просмотр, редактирование и удаление игр.
- Поиск игр по названию.
- Фильтрация по платформам и статусам.
- Сортировка и постраничный вывод.
- Интеграция с RAWG API для поиска информации об играх.
- Автоматическое заполнение информации об игре и её обложки.
- Ведение игрового прогресса и выставление оценок.
- Просмотр статистики личной коллекции и топа игр.
- Разделение данных между пользователями.

## 9. Дополнительная информация

При первом запуске приложения автоматически создаются стандартные игровые платформы, если они отсутствуют в базе данных.

Миграции Alembic используются для создания и обновления структуры базы данных.

Файл `.env` содержит индивидуальные настройки и секретные ключи и не должен загружаться в репозиторий. Для настройки используется шаблон `.env.example`.
